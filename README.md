# OSHC ARMS - Accreditation Reporting and Monitoring System

This is the static landing page for the OSHC ARMS portal.

## Deployment for Hostinger
To deploy this on Hostinger:
1. Ensure all files except the `.git` folder are placed directly inside the `public_html` directory.
2. The `index.html` must be in the root of `public_html`.

## Local Development
Simply open `index.html` in any modern web browser.
